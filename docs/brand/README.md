# Brand

ReFHIR's logo is a grid of four resource blocks, one of them lit. The blocks stand for FHIR
resources; the lit one is the result that just changed, which is what a live query delivers. The
lit block has one sharp corner, a flat echo of the flame in FHIR's own identity.

## Files

| File | Use |
| --- | --- |
| [`refhir-logo.svg`](refhir-logo.svg) | Mark and wordmark, for light backgrounds. The default. |
| [`refhir-logo-reversed.svg`](refhir-logo-reversed.svg) | Mark and wordmark, for dark backgrounds. |
| [`refhir-mark.svg`](refhir-mark.svg) | The mark alone, for light backgrounds. |
| [`refhir-mark-reversed.svg`](refhir-mark-reversed.svg) | The mark alone, for dark backgrounds. |
| [`refhir-icon.svg`](refhir-icon.svg), [`refhir-icon-512.png`](refhir-icon-512.png) | Square app icon, for avatars and package pages. |
| [`social-preview.png`](social-preview.png) | 1280 by 640 card. Upload it under Settings, Social preview on GitHub. |

The SVGs are the source of truth. The wordmark is Inter ExtraBold with tracking of -3.5%,
converted to outlines so it looks the same without the font installed. Inter is licensed under the
SIL Open Font License.

## Color

| Name | Hex | Use |
| --- | --- | --- |
| Ember | `#f2481c` | The lit block. Use it for one thing at a time. |
| Ink | `#0f1d2b` | Text, the dark blocks, dark backgrounds. |
| Paper | `#faf8f3` | Light backgrounds, and blocks on dark. |
| Clinical | `#005a8c` | Links and secondary accents. |
| Amber | `#ffb81c` | Highlights next to Ember. Optional. |

Ember is the only color in the mark. Keep it that way: the lit block loses its meaning if a second
block is colored.

## Type

Inter ExtraBold (800) for the wordmark and headlines, with tight tracking. Inter Regular for body
text. IBM Plex Mono for small labels and code.

## Using the logo

- Leave clear space around the logo equal to half a block, about a fifth of the mark's height.
- Keep the mark at 16 px or larger and the full logo at 96 px wide or larger.
- Use the reversed files on Ink or any dark photo, never the default ones.
- Do not recolor the blocks, rotate the mark, move the lit block, or stretch the logo.
- Do not use the mark to suggest that HL7 endorses ReFHIR.
